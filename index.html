Gallery Code Breaker

Background

The latest group of astronauts sent up with Artemis are stuck on the moon as their engines have failed. They need a specific code to restart the engines, but none of the scientists are around to tell them. The scientists did hide the code in a number of puzzles. It's your job to complete the puzzles and get the code to restart the engines.

What do you need to do?

Use the information in the gallery to solve each puzzle and get a number for the final code. Once you have all the numbers, go to 'Enter Code' page and enter your code to see if you can restart the engines.

You will have 20 minutes. When you have finished please return the tablet. When you are ready, click the button below.
